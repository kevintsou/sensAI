觸發條件
編譯時，phal_sys_get_all_gpio_input_value 的控制流程走到函式結尾（第 315 行的 return 已註解，函式內沒有其他 return），編譯器發出 control reaches end of non-void function；開 -Werror 時建置直接失敗。若只以警告放行，任何呼叫端取用回傳值時就會踩到未定義行為
後果
